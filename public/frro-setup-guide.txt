========================================
FRRO Form C Desktop Auto-Fill Setup Guide
========================================

This sets up a local server that automatically fills Form C on
indianfrro.gov.in. You only solve the CAPTCHA — everything else
is automated.

========================================
PREREQUISITES
========================================

1. Install Node.js (v18 or higher)
   Download from: https://nodejs.org
   
   Verify installation:
   node --version
   npm --version

2. Install Git (if not already installed)
   Download from: https://git-scm.com

========================================
SETUP - macOS / Linux (automated)
========================================

1. Download "macOS/Linux setup" from the Form C window.
2. Open Terminal and run the downloaded file, for example:
   bash ~/Downloads/frro-setup-macos-linux.sh
3. It clones/updates GokoWeb, installs dependencies and Chromium, then starts
   the helper. Keep that Terminal window open.

========================================
Linux note
========================================

If Chromium reports missing system libraries on Ubuntu/Debian, run:
   cd ~/Downloads/GokoWeb && npx playwright install-deps chromium

========================================
SETUP - Windows
========================================

1. Download "Windows setup" from the Form C window.
2. Open PowerShell and run the downloaded file, for example:
   powershell -ExecutionPolicy Bypass -File .\frro-setup-windows.ps1
3. It clones/updates GokoWeb, installs dependencies and Chromium, then starts
   the helper. Keep that PowerShell window open.

========================================
HOW TO USE
========================================

1. Run the platform setup script once. It starts the server at
   http://localhost:3456; keep its terminal window open.

2. In the admin panel, open a foreign guest's Form C

3. Click "Desktop: Auto-Submit"

4. A browser window opens with FRRO login page
   - Username and password are pre-filled
   - YOU solve the CAPTCHA and click Sign In

5. After login, the script automatically:
   - Uploads passport photo (resized to <50KB JPG)
   - Navigates to Form C
   - Fills all fields
   - Clicks "Temporary Save and Exit"

6. Done! Check FRRO site to review and submit permanently.

========================================
TROUBLESHOOTING
========================================

Error: "Executable doesn't exist"
  → Run: npx playwright install chromium

Error: "Local server not running"
  → Open terminal and type: frro

Error: "Login timed out"
  → Solve the CAPTCHA within 2 minutes

Fields not filling:
  → Check terminal for "NOT FOUND" messages
   → Correct the details in the Edit view in the Form C modal and run again
