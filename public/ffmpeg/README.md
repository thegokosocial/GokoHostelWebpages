# ffmpeg.wasm worker (static)

Generated by `npm run ffmpeg:assets` (`scripts/copy-ffmpeg-assets.mjs`) from `@ffmpeg/ffmpeg`.

Copies only `worker.js`, `const.js`, and `errors.js`. **Do not** put `ffmpeg-core.wasm` here — it is ~31MB and exceeds Cloudflare Workers’ 25 MiB static-asset limit. Core JS/WASM load from the CDN pin in `processHeroVideo.ts` via `toBlobURL`; the unbundled worker is what fixes the Next/webpack `Cannot find module 'blob:…'` failure.

`dev` / `build` / `cf:build` / `deploy:cf` run the copy first.
